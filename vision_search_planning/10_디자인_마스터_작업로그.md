사용자 확정 사항과 구현자의 기술 선택·검수 기록을 구분한다. 검수 상태를 사용자 승인으로 확대 해석하지 않는다. 전체 화면 재설계는 일시정지 상태를 유지하며 이번 작업 0·1만 수행한다.

- `/gallery/results`의 샘플 대체 목록과 `/gallery/photo/sample-*` 조회를 제거했다. 실제 연결 파일의 결과·상세·영역 선택·확인 후 F2 전달 기능은 유지한다.

### 구현 근거와 경계 — DML-005

- 네이티브 `webkitdirectory`는 선택한 디렉터리 계층의 모든 파일을 평탄한 FileList로 전달한다. 수집기는 경로 깊이로 거르지 않고 이미지 전체와 `webkitRelativePath`를 보존한다. 근거: [MDN webkitdirectory](https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement/webkitdirectory), [MDN webkitRelativePath](https://developer.mozilla.org/en-US/docs/Web/API/File/webkitRelativePath).
- 루트·하위·중첩 폴더7장, 같은 이름/다른 상대경로, 비이미지 혼합, 루트 이미지 없음·빈 선택의 회귀 검사를 추가했다. 브라우저가 전달한 선택 범위 밖의 폴더를 임의 탐색하지 않는다.
- 더보기는 `/gallery/results?view=all`의 실제 파일 목록 모드다. 검색 요약·‘샘플 검색’ 문구를 표시하지 않고, 기존 페이지 나눔·파일명 필터·원본 상세를 재사용한다. 실제 AI 유사도 검색은 여전히 미연결이다.

### 찾은 기록 중복 정책 검토 [제안 · 미확정]

- 중복 기준은 **파일 내용의 SHA-256**이다. 이름·폴더·수정 시간이 달라도 내용이 같으면 중복이며, 이름·크기·시간이 같아도 내용이 다르면 유지한다. 재인코딩/크롭 등 파일 바이트가 달라진 사진을 시각적으로 판별하는 기능은 아니다.
- 기기 안에서만 검사한다. 파일 크기가 다른 경우 불필요한 읽기를 생략하고, 비교가 필요한 파일을 순차로 읽으며 File별 지문은 세션 WeakMap에만 캐시한다. 서버 전송·영속 저장을 추가하지 않는다.
- 검사 중 선택 버튼을 비활성화하고 **중복 이미지를 확인하고 있어요.**를 표시한다. 최초 연결에서는 **확인 중단**, 추가 창에서는 취소·Esc·닫기를 제공한다. 새 요청·화면 종료도 이전 요청을 취소하며, 완료 직전 취소 신호를 확인한 후에만 연결을 갱신한다.
- 모두 중복이면 **이미 연결한 이미지예요. 다른 사진이나 폴더를 골라 주세요.**라고 안내하고 연결을 바꾸지 않는다. 검사 중 읽기 실패는 오류를 안내하고 일부 파일만 먼저 추가하지 않는다. 기존 File·순서·경로·검색 초안·이전 기록은 보존한다.

- [Google Product Search 공식 가이드](https://docs.cloud.google.com/vision/product-search/docs/general-tips)는 여러 구도의 참조 이미지와 배경 맥락 활용을 다룬다. 이는 참조 DB 이미지에 대한 근거이며, 우리 서비스의 다중 질의 사진 성능 향상을 검증한 증거는 아니다. 원본/크롭/원본 픽셀의 배경 마스킹/생성 이미지의 Recall@K 등을 동일 정답셋으로 비교할 것을 제안한다.
- 생성 모델이 로고·흠집·색·형태를 바꾸면 검색 단서가 달라질 위험이 있으므로 생성 이미지를 기본 검색 입력으로 사용하지 않는 방향을 권한다. 이는 설계 판단이며 아직 실험 결과가 아니다. 우선 사각형 크롭, 이후 원본 픽셀을 유지하는 선택적 세그먼트/배경 제거를 검토한다. 세그먼트도 경계/작은 특징 손실을 확인해야 하며 현재 기능인 것처럼 버튼을 노출하지 않는다.
- 원본/크롭 비교 실험은 평가 데이터에서 수행한다. 향후 제품에서 원본을 함께 전송하려면 사용자가 확인한 전송 범위·취소를 별도로 설계해야 하며, 현재 크롭 선택을 원본 전체 전송 동의로 해석하지 않는다. 이미지 생성 서비스·모델 다운로드·유료 API 호출은 하지 않았다.

## DML-20261117-028 — 분실물 여러 참고 사진 입력 [사용자 요청 확정 · 변경 금지]
