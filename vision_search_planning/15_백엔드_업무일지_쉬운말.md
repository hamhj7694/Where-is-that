# 백엔드 업무일지 (쉬운 말 버전)

• 사용자가 쓴 한 문장을 AI가 먼저 읽어서 "지갑", "검은색", "가죽" 같은 검색 조건으로 정리하게 했다.

• 경찰청이랑 포털기관 습득물 정보를 함께 가져오고, 같은 물건은 한 번만 보이게 정리했다. 건수와 페이지도 실제 남은 결과에 맞게 다시 계산한다.

• AI 역할을 두 개로 줄였다. 하나는 말과 사진을 같이 이해하는 역할, 하나는 사진끼리 닮은 정도를 재는 역할이다.

• 사진이 없어도 "딸기 그림이 있는 지갑"처럼 말로 한 특징을 알려주면 공개 사진을 찾게 했다. 사진만 있는 글도, 설명만 있는 글도 같이 순위에 넣는다.

• 검색이 30초 넘게 걸리던 걸, 요청 연결을 재사용하고 동시에 더 많이 물어보게 바꿔서 13초대로 줄였다.

• 사전학습된 CLIP·YOLOE를 붙였다. 물건이 여러 개일 때만 사진을 자르고, 후보 중 딱 8개만 비교해서 시간을 아낀다. 새로 학습시키지는 않았다.

• 공식 코드표(분류·색상·지역)를 받아서 경찰청 전용 필터로 처음부터 좁혀 찾게 했다. 이제 200페이지까지, 설정하면 마지막 페이지까지 볼 수 있다.

• 사진 속 물건이 2개 이상이거나 종류가 2가지 이상이면 AI가 한 번 더 확인해서 자르게 했다.

• 실제 사진 12건으로 직접 평가해 봤다. 점수가 전부 100점으로 뭉쳐 1위가 엉망이던걸 고쳤고, 지금은 사진으로 찾으면 1위를 100% 맞춘다. 말로만 찾을 때 점수가 애매하면 AI가 사진을 다시 보게 했다.

• 코드로 못 좁히는 지역(구·동 등)은 버리지 않고 글에서 다시 확인하게 했고, 외부에서 상태를 묻는 요청(/health)도 404가 안 나게 고쳤다.

• 검증: 백엔드 테스트 97개 통과, 실제 호출도 정상(200) 확인. 키와 토큰은 서버에만 두고 문서에는 적지 않는다.
