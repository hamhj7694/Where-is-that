## 1. 지금 구현된 것

- **AI 역할 2개**: `multimodal`(자연어·이미지·joint 해석, AND/OR/NOT 조건, 맥락 채점) + `imageSimilarity`(사진/code 임베딩 유사도). `llm`/`vlm`/`vision`은 호환용 별칭일 뿐 현재 역할이 아니다.
- **유사도 기본값**: `GEUGEO_AI_SIMILARITY_PROVIDER=local-clip`. CLIP `ViT-B-32` + `laion2b_s34b_b79k`, YOLOE `yoloe-11s-seg.pt` 사전학습 가중치만 사용. **파인튜닝 없음**. 모델 파일은 `backend/data/models/`(gitignored).
- **LangGraph 경로**: 사진 없으면 `LLM`, 사진 있으면 `VLM(설명)` → `joint 멀티모달`. 사진 비교는 `수집 → (VLM census) → 카테고리 범위 선택 → 로컬 임베딩 → (실패 시) 멀티모달 폴백 → 설명 점수`. 로컬 점수 성공 시 폴백 생략.
- **크롭 게이팅**: 객체 수 ≥ 2 **또는** 객체 종류 수 ≥ 2일 때만 YOLOE 크롭. 단일 객체는 원본 유지. VLM census가 사진별 `objectCount`/`objectTypes`를 한 번의 배치 호출로 받아 OR 조건에 더한다(`GEUGEO_VLM_CROP_CENSUS`, 기본 true).
- **점수 보정 분리**: 사진↔사진은 0.45~1.00, 텍스트↔사진은 0.10~0.45 구간을 0~100으로 환산. 텍스트 전용 점수가 평평하면(최고 < 70 또는 1·2위 차 < 5) 멀티모달 폴백.
- **공식 코드표 필터**: 분류 45종·색상 85코드/39표시명·지역 17시도. `getLosfundInfoAccToClAreaPd`/`getPtLosfundInfoAccToClAreaPd` 전용 API 사용. 코드 없는 값(구·동 등)은 기존 텍스트 필터 폴백.
- **스캔 상한**: `GEUGEO_LOSTFOUND_MAX_PAGES` 기본 200, `0`이면 마지막 페이지까지. 프론트 기본값 200.
- **데이터 소스 2종만**: 경찰청 습득물정보 `15058696`, 포털기관 습득물정보 `15057670`.
- **헬스**: `GET /api/health`와 `GET /health`가 같은 응답(`include_in_schema=False` 별칭).

## 2. 임의 변경 금지 (사용자 확정)

- `LOST_RESULT_CHANNELS = ['combined','context','image']` — 섹션 순서/구분선/확정 4개 영역 레이아웃·카피·카드 크기·상태·데이터 경계 변경 금지.
- AI 안내·동의는 팝업이 아니라 `http://127.0.0.1:5173/lost-found` 하단 요약. AI 실패 시 원문 검색 폴백.
- 직접 찾기는 AI 점수·재정렬 없이 공개 API 순서 유지, 전체 API 검색 + 건수·페이지 재계산.
- `/gallery`에 `[AI로 조건 정리]` 버튼 금지. `/gallery`·`/lost-found` 모두 검색창 이미지 클립보드 붙여넣기 가능.
- Kakao REST 키·토큰·`POLICE_SERVICE_KEY`는 서버 env 전용. JS 키만 `GET /api/lostfound/map-config`로 전달하고 키 값은 비노출.
- DML은 기존 항목 수정·삭제 금지. 새 항목만 추가하고 `[FRONTEND]`/`[BACKEND]` 태그로 기록.
