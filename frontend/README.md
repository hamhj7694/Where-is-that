## Windows 폴더·파일의 실제 위치 연결

Windows에서 `npm run dev`는 웹 서버와 기기 내 사진 연결 프로그램(`127.0.0.1:5178`)을 함께 실행한다. 갤러리 연결/이미지 추가의 사진·폴더 선택 버튼은 Windows 기본 선택창을 열고, 사용자가 고른 파일의 **실제 절대경로**를 함께 받는다. 특정 사용자 경로를 코드에 넣거나 기준 경로를 직접 입력할 필요가 없다. 폴더를 고르면 하위 폴더 이미지까지 포함한다.

이미 실행 중인 웹 서버를 재시작하지 않고 연결 기능만 켜려면 별도 터미널에서 `npm run dev:local-gallery`를 실행한다. 연결 프로그램이 없는 환경에서는 기존 브라우저 선택 방식으로 전환되며, 브라우저가 주는 상대경로와 수동 위치 설정만 사용할 수 있다. `npm run dev:web`는 웹 서버만 실행한다.

이 기능은 현재 **Windows 로컬 개발 환경용**이다. 배포 웹사이트에서 각 방문자의 절대경로를 받으려면 해당 사용자 PC에 로컬 연결 프로그램을 설치·실행하는 배포 방식이 추가로 필요하다. 일반 웹브라우저만으로 절대경로를 얻는 기능은 아니다. 프로덕션 빌드는 이 개발용 연결을 시도하지 않는다.

연결 프로그램은 localhost에서만 실행되고 허용된 개발 웹 주소와 세션 토큰을 확인한다. 사용자가 명시 선택한 파일·폴더 범위만 읽으며 외부 서버로 사진이나 경로를 전송하지 않는다. 읽기가 끝나면 임시 선택 권한을 해제한다. 사진과 경로는 프론트엔드 세션 메모리에서만 보관하며 새로고침 시 연결이 사라진다. 취소·실패는 기존 갤러리를 바꾸지 않는다.

```powershell
npm run lint
npm run typecheck
npm test
npm run build
```

## 구현 범위

- `/`: 비로그인 홈, `/gallery`: 갤러리에서 사진 찾기, `/lost-found`: 분실물 찾기.
- 네비게이션의 홈 항목은 제거하고 로고로 홈에 복귀한다. 두 검색 모드는 네비게이션 바로 아래의 전환 영역에 배치한다.
- 경로별 독립된 텍스트·참고 사진. 모드를 바꿔도 서로의 사진을 자동 전달하지 않는다.
- 실제 로컬 사진 미리보기/변경/삭제, 드래그 앤 드롭, 이미지 디코드 오류, 빈 입력 안내.
- 실제 폴더/다중 사진 선택. 연결한 자료 전체를 검색 대상으로 표시한다. 참고 사진은 검색 모집단을 대신하지 않는다.
- 글만/사진만/혼합의 검색 입력 확인. F2 요청 계약은 항상 이미지·설명조건 두 경로다.
- 반응형 내비·로그인 안내·갤러리 관리·사진 처리 안내·네이티브 모달.
- 한글 IME 조합 중 Enter 전송 방지, Shift+Enter 줄바꿈, 키보드 탭·모드 화살표·focus·Escape.

## 아직 연결하지 않은 기능

AI/VLM/임베딩·검색 결과·경찰청 API·계정 인증·서버 원본/벡터 저장·로컬 인덱스 영속화는 구현하지 않았다. 파일은 메모리와 Blob URL로만 미리 보고 서버로 전송하지 않는다. 새로고침하면 연결과 입력이 사라진다. 검색 버튼은 현재 입력 요약을 열며 검색 성공/로딩을 꾸미지 않는다. 사진 예시는 샘플이다.

추후 실제 검색은 features/search/model.ts의 입력 계약에 어댑터를 연결한다. 모델 키와 비밀값을 프론트엔드 환경변수에 넣지 않는다.
