# 그거어디? Frontend

홈·검색 입력 화면 1차 구현. React + TypeScript + Vite.

```powershell
cd "C:\Users\mbc\Documents\git\비전 AI 활용하여 웹서비스 만들기\frontend"
npm install
npm run dev
```

개발 서버: http://127.0.0.1:5179

## 인증 (회원가입·로그인)

`/auth/login`에서 **이메일 회원가입/로그인**과 **카카오 로그인**을 제공한다. 인증은 모두 `[backend/](../backend/README.md)`의 FastAPI 서버가 처리하며, 프론트엔드에는 **카카오 키를 포함한 어떤 비밀값도 넣지 않는다.**

- `npm run dev`를 실행하면 Vite가 로컬 갤러리 브릿지와 함께 FastAPI 서버(`127.0.0.1:8000`)도 자동으로 실행하고, `/api` 요청을 그 서버로 프록시한다.
- 서버를 직접 실행하거나 키를 입력하려면 `backend/.env.example`을 `backend/.env`로 복사해 값을 채운다. 카카오 JavaScript 키·REST API 키·클라이언트 시크릿은 **서버 .env에만** 있다.
- 카카오 콘솔과 서버 `.env`에 `http://127.0.0.1:5179/auth/kakao/callback`을 Redirect URI로 설정한다. 로그인도 `http://127.0.0.1:5179`에서 시작한다. `.env`를 바꾼 후 백엔드를 재시작한다.
- 로그인 상태는 서버 세션 쿠키(HttpOnly·SameSite=Lax)로 유지된다. 브라우저를 새로고침해도 세션이 살아 있고, 로그아웃하면 서버 세션과 쿠키가 삭제된다.
- `npm run dev:web`은 웹 서버만 실행한다. 인증을 쓰려면 백엔드를 별도로 띄워야 한다.

## Windows 폴더·파일의 실제 위치 연결

Windows에서 `npm run dev`는 웹 서버와 기기 내 사진 연결 프로그램(`127.0.0.1:5178`)을 함께 실행한다. 갤러리 연결/이미지 추가의 사진·폴더 선택 버튼은 Windows 기본 선택창을 열고, 사용자가 고른 파일의 **실제 절대경로**를 함께 받는다. 특정 사용자 경로를 코드에 넣거나 기준 경로를 직접 입력할 필요가 없다. 폴더를 고르면 하위 폴더 이미지까지 포함한다.

이미 실행 중인 웹 서버를 재시작하지 않고 연결 기능만 켜려면 별도 터미널에서 `npm run dev:local-gallery`를 실행한다. 연결 프로그램이 없는 환경에서는 기존 브라우저 선택 방식으로 전환되며, 브라우저가 주는 상대경로와 수동 위치 설정만 사용할 수 있다. `npm run dev:web`는 웹 서버만 실행한다.

이 기능은 현재 **Windows 로컬 개발 환경용**이다. 배포 웹사이트에서 각 방문자의 절대경로를 받으려면 해당 사용자 PC에 로컬 연결 프로그램을 설치·실행하는 배포 방식이 추가로 필요하다. 일반 웹브라우저만으로 절대경로를 얻는 기능은 아니다. 프로덕션 빌드는 이 개발용 연결을 시도하지 않는다.

연결 프로그램은 localhost에서만 실행되고 허용된 개발 웹 주소와 세션 토큰을 확인한다. 사용자가 명시 선택한 파일·폴더 범위만 읽으며 외부 서버로 사진이나 경로를 전송하지 않는다. 읽기가 끝나면 임시 선택 권한을 해제한다. 연결한 사진은 이 브라우저의 IndexedDB에 보관해 페이지 이동·새로고침 후에도 유지되고, 절대경로 정보는 세션 메모리에만 둔다. 취소·실패는 기존 갤러리를 바꾸지 않는다.

```powershell
npm run lint
npm run typecheck
npm test
npm run build
```

## 구현 범위

- `/`: 비로그인 홈, `/gallery`: 갤러리에서 사진 찾기, `/lost-found`: 분실물 찾기.
- 네비게이션의 홈 항목은 제거하고 로고로 홈에 복귀한다. 두 검색 모드는 네비게이션 바로 아래의 전환 영역에 배치한다.
- 경로별 독립된 텍스트·참고 사진. 모드를 바꿔도 서로의 사진을 자동 전달하지 않는다.
- 실제 로컬 사진 미리보기/변경/삭제, 드래그 앤 드롭, 이미지 디코드 오류, 빈 입력 안내.
- 실제 폴더/다중 사진 선택. 연결한 자료 전체를 검색 대상으로 표시한다. 참고 사진은 검색 모집단을 대신하지 않는다.
- 글만/사진만/혼합의 검색 입력 확인. F2 요청 계약은 항상 이미지·설명조건 두 경로다.
- 반응형 내비·이메일 회원가입/로그인·카카오 OAuth 로그인·갤러리 관리·사진 처리 안내·네이티브 모달.
- 한글 IME 조합 중 Enter 전송 방지, Shift+Enter 줄바꿈, 키보드 탭·모드 화살표·focus·Escape.

## 현재 연결 상태 (2026-11-23 갱신)

**계정 인증**은 FastAPI 서버(DB·비밀번호 해싱·세션, 카카오 OAuth 포함)로 연결했다. **AI·검색·공개 API도 연결했다.** `/lost-found`는 제출 즉시 `POST /api/ai/search/prepare`로 조건을 분석하고, `POST /api/lostfound/search`·`/api/lostfound/browse`로 경찰청·포털기관 습득물을 조회한다. 사진이 없어도 자연어 시각 특징으로 공개 사진을 분석하고(`POST /api/ai/vision/match-public`), 사진만 있는 항목과 설명만 있는 항목을 같은 후보 풀에서 점수화한다. `/direct-search`는 공식 코드표 기반 전용 필터 API로 전체를 스캔하되 AI 점수로 재정렬하지 않는다. AI 실패 시 원문 검색으로 폴백한다.

**여전히 로컬/브라우저에만 두는 것**: F1/F2 검색 입력·참고 사진·갤러리 원본, F3 사진과 검색정보(계정과 무관). 파일은 Blob URL로 미리 보고 서버로 전송하지 않는다. 연결한 갤러리는 IndexedDB에 보관해 새로고침 후에도 유지되고, 검색 입력은 새로고침하면 사라진다. **서버 원본/벡터 저장·로컬 인덱스 영속화는 하지 않는다.** 모델 키·비밀값은 프론트엔드 환경변수에 넣지 않는다.

아키텍처·이관 런북·금지 사항은 `../vision_search_planning/14_코덱스_이관_핸드오프.md`를 따른다. 위 "검색 버튼은 요약만 연다 / 사진 예시는 샘플이다" 같은 과거 문구는 이 절이 대체한다.
