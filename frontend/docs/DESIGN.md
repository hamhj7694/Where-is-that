# 그거어디? — 홈·검색 입력 1차 디자인

## Unslop 적용 방향

- Product: 기억나는 말과 참고 사진으로 내 갤러리와 공개 습득물 후보를 찾는 도구.
- Character: 차분함, 정확함, 발견하는 순간의 작은 즐거움.
- World: 실제 사진과 업무 스크린샷을 정돈한 contact sheet.
- Moments: 실제 사진·편집 가능한 일정표 예시 한 곳에 색과 디테일을 집중한다.
- Signature: 사진의 작은 노란 초점 코너. 선택은 잉크 테두리·체크·텍스트를 함께 사용한다.

사용자가 바로 개발하도록 지시했으므로 unslop의 direction 대기 예외를 적용해 진행했다.

## 기존 시안 진단과 패스

기존 시안은 기본 정렬이 되어 있었지만 반복되는 둥근 컨테이너와 강조색 링크, 큰 여백, 서비스 고유의 사진 경험 부족이 있었다. 사용자가 색상 변경을 요청해 이전 베이지·오렌지 팔레트를 계승하지 않았다.

1. Spacing:4px 기반, 내부 간격보다 그룹 사이 간격을 크게. 입력창과 도구행을 하나로 묶는다.
2. Color:#FAFAF8 / #222322 / #E5DB72. UI는 뉴트럴, 사진이 색을 담당한다. 주 버튼은 잉크 채움, 노랑에는 잉크 글자만.
3. Icons:Lucide18px/1.6stroke, 브랜드 검색 초점만 같은 선 굵기의 전용 벡터.
4. Copy:06 원고의 기능명·설명·입력·행동·한계 안내 유지. 현재 실제 동작을 설명하는 화면 체험 고지는 추가했다.
5. Type:공식 Pretendard Variable 로컬 호스팅.400/500 중심, 로고600. 한글 keep-all과 의미 단위 줄바꿈.
6. Layout:데스크톱은 검색 작업 영역+기능적으로 입력되는 예시 contact sheet. 태블릿·모바일은 검색→예시 순서로 스택.
7. Details:컨트롤8px/사진12px/컴포저20px, 44px 이상 터치. native dialog의 focus trap/Escape/복귀 사용.
8. Visuals:허가된 기존 공개 샘플 사진과 HTML 일정표. 이미지 생성 서비스를 사용하지 않았다.
9. Motion:상태를 설명하는 색/테두리 변경만160ms. 루프·등장 애니메이션 없음, reduced-motion 대응.

## 제품 경계와 문서 충돌

- 1차 구현 중 사용자 추가 지시: 네비게이션 홈 항목 삭제, '내 갤러리에서 사진 찾기'를 '갤러리에서 사진 찾기'로 축약, 두 검색 전환 버튼은 헤더 직하단으로 이동. 현재 프론트엔드에 적용하며 기존 Figma는 변경하지 않는다.
- 데스크톱의 중복된 검색 링크는 직하단 검색 내비게이션으로 통합했다. 상단은 브랜드·소중한 것들·설정·로그인, 바로 아래는 두 검색 방식이다. 모바일 메뉴에서도 두 검색 경로에 접근할 수 있다.

- 최신 사용자 요청이 루트 AGENTS와00의 과거 'Figma 승인 전 구현 보류'보다 우선한다. 이번 승인은 프론트엔드 홈·검색 입력에 한정한다.
- 05 §1.1 '선택한 사진에서 찾아요' 같은 오래된 초안은06의 '연결한 갤러리 전체' 계약으로 대체한다.
- unslop의 영문 기본 폰트·짧은 라벨·32px 내비 예시는 한국어 카피·44px 타깃에 맞게 조정했다.
- 01의 과거 컬러보다 새 색상 요청이 우선한다. 제품 정책은 변경하지 않는다.
- 현재 파일 선택은 실제 브라우저 동작이지만 인덱싱·AI 검색·서버 저장이 아니다. UI에서 구분하며 허위 결과/진행률을 만들지 않는다.
