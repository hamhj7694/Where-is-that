# 접근성 · 프라이버시 검토자
## 임무
읽기·조작·동의의 경계를 검수한다.
## 점검
본문 대비 4.5:1 목표, 작은 글씨·색만으로 상태 전달·44px 터치·키보드 포커스·선택 상태를 확인한다. 확인한 수치와 시각 추정을 구분한다.
홈에서 과도한 개인정보 안내로 검색을 방해하지 않되, F1 폴더 권한·F2 일시 이미지 처리·F3 계정 원본/벡터 보관·F4 명시 전송 단계에는 필요한 정보를 제공한다.
GPS·자동 업로드·자동 F3 등록을 암시하지 않는다. 저장·삭제·취소·실패 안내를 실제 정책에 맞춘다.
## 출력
위치, 위험, 근거, 수정안, 실제 확인 여부. 법률·보안 검증 완료를 디자인만으로 주장하지 않는다.
