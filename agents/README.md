# 역할별 에이전트

모든 역할은 먼저 루트 `AGENTS.md`와 해당 역할 파일을 읽는다. 역할 정의를 만들었다는 사실과 실제 에이전트를 실행했다는 사실은 별도로 보고한다.
디자인·화면·카피 판단은 `vision_search_planning/11_프론트엔드_픽스_확정문서.md`, `10_디자인_마스터_작업로그.md`, 현재 `frontend/src/**` 코드를 기준으로 한다. **파일명에 `_old`가 포함된 문서는 읽지 않는다.** 인용·요약·비교·참조도 금지한다. 과거 기획·화면·카피·Figma 문서는 모두 `_old`로 이관되었으므로 현재 근거로 쓰지 않는다. 네 확정 영역(갤러리에서 사진 찾기·분실물 찾기·찾은 기록·사진 등록해 두기)은 변경 금지다.

| 파일 | 역할 | 현재 책임 |
|---|---|---|
| 00_orchestrator.md | 오케스트레이터 | 범위·순서·의사결정·실행 통합 |
| 01_product_planner.md | 제품 기획자 | 요구사항·권한·저장 경계 |
| 02_product_designer.md | 제품 디자이너/아트디렉터 | 기존 시안 비평·레퍼런스·컨셉·Figma 설계 |
| 03_ux_researcher.md | UX 리서처 | 과업·레퍼런스 근거·실사용자 검증 계획 |
| 04_ux_writer.md | 한국어 UX 라이터 | 화면 카피·행동명·오류/안내 |
| 05_frontend_engineer.md | 프론트엔드 개발자 | 반응형·상태 계약·핸드오프 가능성 |
| 06_backend_engineer.md | 백엔드 개발자 | 인증·저장·API·위치 상태 계약 |

| 08_accessibility_privacy.md | 접근성·프라이버시 검토자 | 대비·터치·포커스·동의·삭제 |
| 09_vision_search_engineer.md | 비전 검색 엔지니어 | 사진/OCR·벡터·검색 결과 의미 검토 |

권장 순서: 기획 경계 확인 → 디자이너의 기존 화면 비평·레퍼런스 → UX 카피 → 핵심 화면 설계 → 개발 관점 검토 → 실제 Figma 제작 → QA·접근성 검수.
현재는 D0 디자인 작업이므로 개발 역할은 검토만 수행하며 제품 코드를 구현하지 않는다.
