### 최종 합의된 F2 검색 결과 정책 [AGREED]

| 항목 | 최신 결정 |
|---|---|
| 검색 입력 | 자연어만 / 사진만 / 자연어+사진 모두 지원 |
| 검색 원천 | **이미지**(유효 공공 사진) + **맥락**(사진 없어도 전체 공개 기록) |
| 사용자 결과 | **종합 / 이미지 / 맥락** 3개 독립 결과 채널 |
| 종합 | 이미지·맥락 후보의 **OR 합집합** 기반 재랭킹. 사진 없는 레코드도 종합 후보 가능 |
| 정렬 | 종합·이미지·맥락 **각각 독립 순위** |
| 중복 정책 | **채널 간 동일 물건 중복 허용**, 동일 채널 내 동일 기록 중복 제거 |
| 이유 | 종합 7위·맥락 4위인 물건은 **맥락 더보기에서 4위**로 보여야 함. 다른 채널 노출로 제외하지 않음 |
| 미리보기 | **각 최대 3개**(3+3+3), 실제 0~2개면 있는 만큼만. **3개 수치 자체는 사용성 실험 전 임시안** |
| 더보기 | 각 채널 **4위 이후 독립 탐색**, 채널 필터·커서·정렬·복귀 유지 |
| 데이터 결핍 | 실사진 없는 기록은 이미지 채널 제외, **맥락·종합 포함 가능** |
| 점수 | 이미지 점수와 BM25 점수를 단순 평균하거나 일치 확률로 표기하지 않음. OR+RRF를 먼저 시험 |
| 결과 의미 | 유사한 공개 습득물 후보. 동일 실물·소유권·실시간 위치 확정 아님 |

## AI 모듈·기술 변경

- 사전학습 **YOLOE 등 객체 탐지**: 위치 탐지 후 수동/자동 크롭. 모델은 실험 후 결정, **자체 재훈련/Roboflow 어노테이션은 기본 의무 아님**.
- **OCR**: F1 브라우저 로컬 스크린샷/사진 속 글자 검색을 **필수 기능**으로 반영. 구체 OCR 모델·성능·색인 방식은 미검증. F2 공개 물품 이미지 OCR은 추가 단서 후보.
- **이미지/텍스트 임베딩**: 유사도 검색용 사전학습 모델·모델 ID·전처리 버전 관리.
- **VLM**: F2 공개 실사진의 맥락 사전 분석/질의 사진의 설명·조건 변환이 제품 목표. 실제 제공자·API·비용·처리 정책은 미확정.
- **LLM**: 자연어의 명시 조건·의도를 Structured Output으로 구조화. 매 요청 호출이 반드시 필요한지는 비교 검증.
- **LangChain + LangGraph**: **F2 Python 서버**의 제한된 검색 워크플로 분기·검색 병렬화·재시도·부분 실패 조정 방향. LLM이 검색 순위 점수를 임의로 만들지 않음.
- **MCP**: 당장 필요한 외부 도구 생태계가 없으므로 MVP 제외. 내부 Python 함수/SDK/API 클라이언트로 연결.
- **직접 모델 학습과 평가셋 구별:** 처음에는 이미 학습된 모델로 PoC하고 **평가용 정답 데이터셋은 반드시 제작**. 미세조정은 부족이 입증될 때 결정.
